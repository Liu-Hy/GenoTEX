## 📝 About

GenoTEX is a benchmark dataset for evaluating automated methods for gene expression data analysis. The benchmark provides:

- **1,384 GTA Problems** across 132 traits
- **911 Datasets** with 152K+ samples
- **Expert-curated** analysis code and results
- **GenoAgent** baseline method using LLM-based agents
